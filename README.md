## 🛠️ How to Run Locally

1. Open your terminal in the project directory:
   ```bash
   cd E:\Shweta\shweta-portfolio
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Open your browser and visit:
   ```
   http://localhost:5173
   ```

---

## 📦 How to Build for Production

```bash
npm run build
```
The optimized files will be generated in the `dist/` directory.

## 🌐 Free 1-Click Deployment (To add to LinkedIn!)

### Option 1: Vercel (Recommended)
1. Push this project to a GitHub repository (`shweta-portfolio`).
2. Go to [vercel.com](https://vercel.com) and sign in with GitHub.
3. Click **"Add New Project"**, select `shweta-portfolio`, and click **Deploy**.
4. You will get a free live URL (e.g. `https://shweta-vikhe.vercel.app`) that you can directly add to your LinkedIn profile under **"Featured Links"** or **"Contact Info"**!

### Option 2: Netlify
1. Go to [netlify.com](https://netlify.com).
2. Drag and drop the `dist/` folder into Netlify Drop, or connect via GitHub.
3. Your portfolio goes live instantly.
